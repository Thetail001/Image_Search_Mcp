## 运行检查

```bash
./check.sh
./check.sh --fast
./check.sh --reverse-only
python tools/status.py --update docs/实施进度.md
```

单元测试默认拦截真实 HTTP 和 DNS 请求。部署脚本测试使用临时目录以及 sudo、systemctl、uv、curl 的替身，不修改系统服务。反向测试在代码副本中注入缺陷，要求指定测试出现断言失败。

CI 覆盖 Python 3.10、3.11 和 3.12。单元测试与脚本检查在三个版本上运行，完整反向测试单独使用 Python 3.12。

## 验证范围

自动检查覆盖输入校验、出站请求构造、下载限制和 MCP 内存传输。它们不证明所有引擎在任意网络下可用，也不替代第三方客户端和真实 systemd 部署验证。

历史真机验证记录见 [2026-10-05 实施记录](archive/implementation-2026-10-05.md)。其中的服务器状态和在线搜图结果仅代表当时环境。

服务整体并发限制、输出预算和日志脱敏检查已列入 ROADMAP。
